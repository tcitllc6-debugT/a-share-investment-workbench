# 多空线筛选与更新入口设计

## 目标

精简多空线选股的筛选界面，修复概念多选的原始 JSON 显示问题，并让设置页可直接检查已签名更新。

## 界面

- 筛选区固定为两行：第一行是八个多空线条件；第二行依次是板块、行业、概念和最小偏离。
- 删除价格、流通市值、成交额、换手率和量比的筛选控件；保留关键行为开关、关键词和扫描操作。
- 结果表移除流通市值列。

## 数据流

`GetAllConcepts` 将解析 `all_stock_info.CONCEPT` 中的 JSON 数组或普通文本，去空、去重、排序后返回概念名称。前端仍只使用 `{ label, value }` 的字符串选项。

## 更新

设置页的“检查更新”调用 `CheckManagedUpdate`。发现新版本时展示版本和更新说明，并复用现有 `ApplyManagedUpdate` 走校验下载、Windows 更新助手与回滚流程；已是最新版本或检查失败时显示明确提示。

## 验证

- 为概念规范化添加单元测试，覆盖 JSON 数组、普通文本、重复值和空值。
- 运行数据层测试和前端生产构建。
