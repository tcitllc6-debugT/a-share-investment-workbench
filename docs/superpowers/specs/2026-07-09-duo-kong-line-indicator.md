# 多空线指标设计

## 目标

在 K 线左侧“趋势”指标组新增固定指标“多空线”，按用户提供公式绘制在主图上，不引入通用公式编辑器。

## 公式

```text
P := (OPEN + HIGH + LOW + 2 * CLOSE) / 5
CCI := EMA(CLOSE, 10)
TW2 := EMA(P, 30)
```

## 绘制

- 细线：`CCI`，线宽 2。
- 粗线：`TW2`，线宽 3。
- 当前值大于等于上一根值时绘红色，当前值小于上一根值时绘绿色。
- 首根没有前值，按红色起笔处理。
- 图上只创建两条曲线；`A1/A2/A3/A4` 是截图软件用于红绿分段的中间输出，不作为四条独立线显示。
- 公式里的 `NODRAW` 变量不单独显示，只作为细线/粗线的数据来源。

## 验证

- 用纯计算测试固定 EMA 起算方式、P 加权价格、红绿分段。
- 前端构建通过。
- Wails 桌面包可正常生成并启动。
