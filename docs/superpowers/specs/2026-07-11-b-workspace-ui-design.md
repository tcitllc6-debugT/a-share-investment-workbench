# B 版 A 股工作台 UI 设计规范

## 目标

将现有 A-Share Desk 重构为顶部一级导航、左侧当前板块二级导航的桌面工作台，同时保留既有行情、K 线、选股、交易日志、AI、自动更新和便携版能力。

## 一级板块

1. 总览
2. 股票自选
3. 市场资讯
4. 多维度选股
5. 持仓中心
6. AI 控制台
7. 设置

K 线分析、异动雷达、基金、定时任务、MCP 和旧研究中心保留兼容路由，但不再作为一级导航出现。

## 二级导航

- 总览：首页
- 股票自选：全部自选、自选分组、价格提醒
- 市场资讯：市场快讯、全球股指、重大指数、行业排名、个股资金流向、板块资金流向、概念资金流向、龙虎榜、个股研报、公司公告、行业研究、当前热门、名站优选
- 多维度选股：形态选股、多空线选股、策略选股
- 持仓中心：交易记录
- AI 控制台：AI 分析记录、股票推荐记录、AI 配置
- 设置：常规设置、数据与缓存、通知设置、更新与备份

导航模型是唯一数据源。路由、顶部导航、二级导航、标题和快捷入口均从该模型派生，不在 `App.vue` 或业务组件中复制菜单数组。

## 桌面布局

- 第一行是 56px 顶部栏：品牌、七个一级入口、股票搜索、市场状态和通知。
- 第二行开始为工作区：216px 二级导航和可滚动主内容区。
- 页面只允许主内容区滚动；顶栏和二级导航固定。业务组件不能再用 `calc(100vh - Npx)` 与外层争夺滚动。
- 顶部一级入口使用文字按钮；二级入口使用文字加 Lucide/现有图标库图标，不使用装饰性图形。
- 主色使用中性灰白，红色只表达 A 股上涨、重要风险或当前选中状态，绿色表达下跌或正常状态；蓝色用于链接和普通操作。

## 响应式与 300% 缩放

- `>=1280px`：标准 B 版，完整顶部导航和 216px 二级栏。
- `960-1279px`：紧凑顶栏，二级栏 184px，隐藏非关键状态文字。
- `720-959px`：一级导航横向滚动，二级栏改为可开合抽屉。
- `<720px`：单列应急模式，顶栏保留板块切换和搜索图标，二级导航通过菜单按钮打开。
- 正文字号不得低于 12px；控件最小可点高度 32px。
- 表格通过明确的 `scroll-x` 保持列可达，不能压缩到文字重叠。
- 弹窗最大宽度 `min(96vw, 1100px)`，最大高度 `88dvh`，内容区独立滚动。

## 页面归属

- 总览复用 `DecisionWorkbench.vue`，修正持仓和选股快捷链接。
- 股票自选复用 `stock.vue`，保留分组、搜索、自选表格和 K 线动作。
- 市场资讯复用 `market.vue` 的 13 个现有标签页，由路由 query 驱动当前栏目。
- 多维度选股使用 `ScreeningHub.vue`：`allStockList.vue`、`DuoKongLineSelector.vue`、`SelectStock.vue` 分别对应形态、多空线、策略。
- 持仓中心新增薄包装页面，直接承载 `TradingRecordManager.vue`。
- AI 控制台新增薄包装页面，承载 `researchReport.vue`、`aiRecommendStocksList.vue` 和 AI 配置视图。
- 设置复用 `settings.vue`；AI 配置入口从 AI 控制台打开设置中的 AI 段落，在完成安全拆分前不复制整份 `SettingConfig` 保存逻辑。

## 兼容约束

- 不重命名或删除现有路由名：`stock`、`market`、`research`、`agent`、`klineAnalysis`、`screening`、`radar`、`settings`。
- 保留 `changeTab`、`changeMarketTab`、`changeResearchTab` 和 `klineSelectStock` 事件桥，直到所有调用者迁移完成。
- 不修改 `frontend/wailsjs/**`、行情后端、数据库模型、更新签名、NSIS、便携版目录结构或服务器协议。
- 不把提示词广场、问答广场、VIP、赞助或社区入口重新放回产品导航。
- macOS 当前仍标为手动 DMG 更新，不展示不存在的应用内替换能力。

## 验收标准

- 七个一级板块与全部二级入口均可达，刷新和深链后仍保持正确选中项。
- 选股 query、市场 query、AI 控制台 query 双向同步。
- 1440x900、1024x768、800x600、639x800 和 390x844 视口无不可达导航、重叠或页面横向溢出。
- Windows 300% 缩放下可以访问所有一级/二级入口、表格操作和弹窗关闭按钮。
- 现有纯 JS 单测、前端构建、Go 全包编译和 Wails Windows 构建通过。
