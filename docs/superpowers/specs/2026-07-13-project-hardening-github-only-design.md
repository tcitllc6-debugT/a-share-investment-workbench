# A股智投工作台稳定化与 GitHub-only 发布设计

## 目标

将当前功能型 Beta 收敛为可公开分发的桌面应用：默认不弹出外部网页，修正多资产账本，降低启动耗时，收紧本地服务边界，并让版本检查、下载和发布全部依赖 GitHub Releases，不再依赖自建服务器。

## 决策

1. 浏览器爬虫测试默认跳过，只有设置 `RUN_LIVE_BROWSER_TESTS=1` 才能启动真实浏览器。应用运行时不自动调用百度股市通页面；需要网页数据时使用明确的后台无头抓取，并优先使用 HTTP/结构化数据源。
2. 内置 AI Web 服务只监听回环地址，使用进程级随机令牌鉴权，限制请求体和会话大小，并随桌面进程统一关闭。
3. 交易账本是持仓唯一事实来源。资产类型各自负责交易金额、估值、盈亏和单位换算，组合层不得重复实现简化公式。
4. 行情刷新采用有限并发和逐资产独立超时；失败时显示数据时间与状态，不把缓存价伪装成实时价。
5. 启动阶段只做数据库兼容性检查和首屏本地读取。资讯、行情、股票基础数据与 K 线更新进入可取消的后台任务，基础数据使用版本校验和原子替换。
6. Vue 路由全部改为懒加载；Markdown 编辑器、PDF 导出、图表与 AI 页面不得进入首屏主包。
7. 更新源采用 GitHub Releases。Release 附带 `manifest.json`、签名文件和平台压缩包；客户端从 GitHub API 获取最新正式版本并继续执行 Ed25519 与 SHA-256 校验。
8. 品牌统一为“A股智投工作台”，新图标使用白蓝科技风、无文字、在 16px 到 1024px 均可识别，并生成 PNG、ICO 与 macOS ICNS 输入资产。

## 安全边界

- 本地服务不得监听 `0.0.0.0`，不得使用通配 CORS。
- AI 密钥及飞书密钥不写入日志；导出配置不包含密钥正文。
- GitHub 更新必须使用 HTTPS，并验证签名、哈希、版本和平台。
- Wails 外部 URL 打开函数只允许 `https`、GitHub 项目页面和用户明确点击触发。

## 验收标准

- 默认运行 `go test ./...` 不启动浏览器、不访问百度股市通且不因未初始化数据库崩溃。
- `go vet ./...` 无不可达代码。
- 前端测试及生产构建通过，路由生成独立页面分包，主包显著小于当前约 6.26 MB。
- 多次期货平仓、债券、贵金属和手续费交易均有回归测试。
- 应用启动不再删除并全量重建股票基础表。
- 仓库与应用中不再出现自建更新服务器地址。
- Windows 便携包可从 GitHub Release 检查并应用更新；macOS 使用 GitHub Release 下载对应产物。
