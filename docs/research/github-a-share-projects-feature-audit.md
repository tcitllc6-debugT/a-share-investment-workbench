# GitHub A 股项目功能审计与吸收建议

## 扫描范围

已检查 `C:\Users\lxd\Desktop\gupiao\github-a-share-projects` 下 16 个项目的 README、顶层模块和许可证。以下建议只吸收产品思路和公开数据接口设计，不直接复制第三方代码。

## 最值得加入的功能

### P0：近期版本

1. **选股结果验证**
   - 来源思路：`myhhub__stock`、`ricequant__rqalpha`、`tkfy920__qstock`。
   - 产品落点：多维度选股侧栏新增“信号验证”。每次扫描结果可选择过去 1/3/5/10/20 日，统计胜率、平均收益、最大回撤和样本数。
   - 价值：解决“筛出来之后到底有没有用”的核心问题，比继续堆筛选条件更重要。
   - 实现边界：复用本地 SQLite K 线缓存，先做日线事件回放，不引入 Python 回测引擎。

2. **涨停生态与市场情绪面板**
   - 来源思路：`simonlin1212__a-stock-data` 的涨停、炸板、跌停、昨日涨停池和连板梯队。
   - 产品落点：总览的“A股市场温度”可展开；市场资讯增加“涨停生态”。
   - 指标：涨停/跌停、炸板率、封板率、连板高度、首板晋级率、题材集中度。
   - 实现边界：本地保存快照并展示来源和更新时间；来源失败时显示上次成功数据。

3. **筹码分布与成本密集区**
   - 来源思路：`myhhub__stock`。
   - 产品落点：K 线分析增加“筹码”图层；持仓中心展示当前价格相对筹码峰的位置。
   - 指标：获利盘比例、平均成本、90%/70% 成本区间、筹码集中度。
   - 价值：与现有多空线、成本价和持仓风险高度互补。

4. **AI 研究委员会报告**
   - 来源思路：`simonlin1212__TradingAgents-astock` 的多角色研究和多空辩论。
   - 产品落点：AI 控制台新增“研究委员会”，由技术面、基本面、政策行业、公告风险、资金龙虎榜、市场情绪和风控七个席位分别给出证据，再生成矛盾点和结论。
   - 实现边界：复用现有 AI 工具和一套模型服务；先并行采集证据、单次汇总，避免昂贵的多轮模型辩论。

5. **数据源健康中心**
   - 来源思路：`akfamily__akshare`、`waditu__tushare`、`simonlin1212__a-stock-data` 的多源与防封策略。
   - 产品落点：设置新增“数据源状态”，显示行情/K线/新闻/公告各来源延迟、上次成功时间、失败原因和当前降级链路。
   - 实现边界：不把大型 Python 库打进安装包；在 Go provider 层实现主源、备源、限速和熔断。

6. **公式指标工作台**
   - 来源思路：`mpquant__MyTT` 的通达信/同花顺公式函数体系。
   - 产品落点：多维度选股新增“自定义公式”，用户粘贴 `EMA/REF/IF/CROSS` 等公式后可预览两根线、验证样本并保存模板。
   - 实现边界：MyTT 无明确许可证，不复制源码；在 Go 中独立实现经过白名单限制的表达式解析器。

### P1：中期版本

7. **组合风险与仓位建议**
   - 来源思路：`microsoft__qlib`、`ricequant__rqalpha`、`yutiansut__QUANTAXIS`。
   - 产品落点：持仓中心增加行业暴露、单票集中度、相关性、波动率、最大回撤和情景压力测试。
   - 输出：只给风险区间和再平衡建议，不自动交易。

8. **策略实验室**
   - 来源思路：`hugo2046__QuantsPlaybook` 的券商金工策略复现、`microsoft__qlib` 的 Alpha158、`vnpy__vnpy` 的因子工作流。
   - 产品落点：多维度选股新增“策略实验室”，提供 RSRS、RPS、低波动、质量、动量和估值等可解释策略模板。
   - 实现边界：先做可解释因子评分和历史验证，不在桌面端训练深度学习模型。

9. **模拟交易与信号复盘**
   - 来源思路：`vnpy__vnpy`、`wondertrader__wondertrader`、`UFund-Me__Qbot`。
   - 产品落点：持仓中心增加完全本地的模拟账户；雷达和选股信号可一键加入模拟观察，记录当时价格、后续收益和止盈止损触发。
   - 价值：为未来自动下单预留订单、成交、风控接口，但当前不连接券商。

10. **事件驱动任务中心**
    - 来源思路：`ricequant__rqalpha` 的调度器、`wondertrader__wondertrader` 的信号与执行分离。
    - 产品落点：把现有定时任务升级为“条件 + 动作”：多空线上穿、公告发布、放量异动、到价提醒可触发通知、AI 分析或加入复盘。

## 暂不建议

- **实盘自动下单**：当前数据、风控、审计和券商适配尚不足，先完成模拟账户和订单领域模型。
- **在桌面端内置 Qlib/VnPy/QUANTAXIS**：会显著增加 Python 环境、安装体积和跨平台故障率。
- **强化学习和自动因子挖掘**：对家庭用户解释成本高、训练资源重，短期价值低于信号验证和组合风控。
- **扩展港股/美股功能**：产品当前定位是 A 股，先把 A 股数据质量和流程做深。

## 推荐实施顺序

1. 信号验证。
2. 涨停生态与市场温度。
3. 筹码分布。
4. AI 研究委员会。
5. 数据源健康中心。
6. 模拟交易与组合风险。
