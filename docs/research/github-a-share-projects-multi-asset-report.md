## 逐项目结论

### AKShare

- 价值：覆盖股票、基金、债券、外汇、期货、贵金属和加密货币的数据目录。
- 建议：参考其字段映射与降级思路，在 Go 中实现独立适配器，不打包 Python。
- 许可证：MIT。

### go-stock

- 价值：作为现有上游兼容对照。
- 建议：只做功能差异与数据库迁移对照，不复用其界面设计。
- 许可证：GPLv3，发布边界需要持续审查。

### abu

## 多资产数据源建议

- 股票与基金：沿用现有东方财富与新浪链路。
- 债券、贵金属、外汇与期货：参考 AKShare 的数据源目录，使用 Go HTTP 适配器重写。
- 人民币汇率：东方财富盘中汇率为主，ECB/Frankfurter 日参考汇率备用。
- 加密货币：Binance 公共行情为主，CoinGecko 公共行情备用。
- 银行理财：手工净值和 CSV，不依赖不稳定抓取。

## 不建议直接加入

- 真实自动下单和账户密钥托管。
- 在桌面包内嵌完整 Python 量化生态。
- 未验证的机器学习荐股模型。
- 无许可证项目的源码。
- 把单一网页接口直接写死在持仓计算代码中。

1. 统一资产账本和迁移。
2. 多资产行情适配与人民币换算。
3. 组合快照和风险分析。
4. 选股结果验证与筹码分布。
5. 涨停生态与数据源健康中心。
6. AI 研究委员会和模拟交易闭环。
