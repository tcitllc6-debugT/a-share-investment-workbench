# A股智投工作台用户手册

## 软件定位

A股智投工作台是一套本地优先的桌面投研工具，面向 A 股日常观察、选股、持仓管理和复盘。主要数据保存在本机，行情、资讯与公告按需从公开数据源获取，AI 服务由用户自行配置。

## 工作区

- **总览**：集中查看自选与股票持仓、实时涨跌、市场快讯、今日关注和常用工具入口。
- **股票自选**：管理分组和自选股，查看实时行情、多周期 K 线、分时、资金、公告、研报、成本和 AI 研判。
- **市场资讯**：聚合市场快讯、全球股指、重大指数、行业排名、资金流向、龙虎榜、公告与研报。
- **多维度选股**：包含形态选股、多空线选股和策略选股，筛选结果可直接打开本地多周期 K 线复核。
- **持仓中心**：统一记录股票、基金/ETF、债券、贵金属、外汇、期货、加密资产和银行理财，按人民币汇总市值、成本与盈亏。
- **AI 控制台**：管理模型服务、提示词模板、分析记录和股票推荐记录。
- **设置**：管理主题、数据源、通知和更新。
- **关于**：查看版本、开源说明、源码和更新状态。

## 快速开始

1. Windows 用户解压便携版后运行“启动 A股智投工作台.cmd”，或直接运行主程序。
2. 首次启动会在程序目录下创建 `data` 文件夹，用于保存数据库、配置、缓存和更新状态。
3. 在“股票自选”中搜索股票名称或代码并关注；需要记录成本时填写价格和数量。
4. 在“持仓中心”录入资产交易，在总览查看聚合结果。
5. 需要 AI 研判时，在“AI 控制台 > AI 配置”中添加模型服务并测试连接。

## 数据与隐私

- 自选、交易日志、模型配置和研究记录默认保存在本机 SQLite 数据库。
- API 密钥不会显示明文，也不会随普通设置导出。
- 行情、资讯、研报和公告来自公开网络或用户配置的数据源，第三方服务的可用性与准确性由对应服务决定。
- 提示词模板默认使用本地模式，不依赖上游社区服务器。

## 在线更新

应用仅从本项目的 GitHub Releases 获取更新清单和安装包。启动后会在后台检查正式版本；发现新版本时提示更新，也可以在“设置”或“关于”中手动检查。下载完成后仍会校验 Ed25519 签名与 SHA-256 摘要，更新失败会保留原程序并支持回滚。

项目源码与发布页：<https://github.com/tcitllc6-debugT/a-share-investment-workbench>
